# Frontend

React + Vite + TypeScript 前端，用于展示任务、事件、告警、攻击图和溯源结果。

## 启动

先在仓库根目录启动后端：

```bash
python -m uvicorn backend.main:app --reload
```

再启动前端：

```bash
cd frontend
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。Vite 将 `/api` 代理到 `http://127.0.0.1:8000`。

页面默认选择已导入的真实任务，不再自动打开 Mock。真实日志导入与本地保存见 `collectors/LAB_IMPORT.md`。测试用 Mock 仍保留在 testdata，不会自动混入 API。

## 连接真实任务

前端只请求后端数据，不生成告警、攻击图或溯源结果。在任务输入框填写后端已有的任务 ID。攻击图本次验收任务为 `task_frontend_e2e_002`，预期 14 个节点、30 条关系；该任务必须由对应后端提供，仓库三节点 Mock 不可替代验收。

若后端不在本机 8000 端口，在 `frontend/.env.local` 配置实际地址后重新启动 Vite：

```dotenv
API_PROXY_TARGET=http://your-backend-host:8000
```

只填写可信后端的协议、主机和端口；前端仍使用已有 `/api/...` 公共路径。默认代理保持 `http://127.0.0.1:8000`。`.env.local` 不提交 Git。

## 数据展示与交互

- 攻击图使用 Cytoscape 绘制后端节点和可解析的关系。节点超过 150 个且带告警证据时，默认只显示与告警相关的子图并在画布上方标明“正在显示 X / Y”，一键即可重置；也可按节点类型逐类开关。
- 默认力导向布局，可切换分层布局；支持滚轮/按钮缩放、画布移动、节点拖动、重新布局、适配全图和全屏画布。画布操作说明收在工具栏的问号按钮里，不占用页面空间。
- 关系标签默认在悬停或选中时出现，避免密集图中文字覆盖；关系超过 120 条时“显示全部关系标签”会被禁用并说明原因。不因隐藏标签而删除关系。
- 点击节点查看完整属性和关联关系；点击边查看 `evidence_event_ids`、`evidence_alert_ids`、置信度、时间及属性。节点与关系改用搜索框（按名称/ID/关系/端点过滤，回车定位），不再使用包含上千条目的下拉框。缺失端点的关系会明确提示，证据仍保留在溯源结果中。
- 画布获得焦点后，方向键移动、`+`/`-` 缩放、`0` 适配全图。
- 事件表保留时间、主机、来源、行为和网络摘要。行点击或“详情”按钮打开完整事件；`Esc` 关闭并恢复焦点。
- 告警证据 JSON 显示样本数、持续时间、中位间隔、规律度和大小稳定等字段，保留未知字段及原文；普通文本和无效 JSON 保留文本显示。
- 概览展示当前任务告警的最高分，不再把攻击阶段最高分称为“证据置信度”。当最高告警标记 `heuristic_not_probability` 时显示 `0.60 / 1.00（启发式）` 而不是百分数或 `90 / 100`，避免被读成攻击概率；没有告警时显示 `-` 并说明原因。
- 溯源结果的归因区块按字段结构化展示：候选路径、APT 相似度、阶段路径、存储到外传候选、结论边界、大模型复核；不再把 `attribution` 直接 `JSON.stringify` 到页面。证据索引默认只列前 12 条，可展开。

## 文案与语言

接口字段保持英文契约值（`action`、`tactic`、`relation`、`detector` 等），界面通过 `src/labels.ts` 统一翻译，原始值保留在 `title` 或折叠区里以便追溯。规则中文名、ATT&CK 技术中文注释、后端追加的英文说明句都在该文件维护；新增检测规则时请同时补充中文名。

## 视觉与布局走查

```bash
node frontend/scripts/ux-walkthrough.cjs <task-id> <output-dir>
```

脚本用 Playwright 在 1440×900 与 390×844 两个视口逐个打开五个页面，截图并输出 `report.json`，其中包含：可见英文文本节点数、≥120 字符的 JSON 代码块数、元素横向溢出、页面级横向滚动和控制台消息。验收标准是溢出为 0、无页面级横向滚动、控制台为空。需要先启动后端与 Vite。

脚本还会真实点击并断言 10 项交互（攻击图筛选/搜索/全屏、事件详情对话框、告警证据索引、溯源证据索引与归因折叠）。任一项失败脚本以非零码退出，适合放进验收流程。

脚本还会在桌面视口对攻击图控件做点击断言（默认只显示告警相关子图、重置筛选、只看告警相关开关、节点类型筛选、搜索定位节点、全屏画布进出），任何一项失败会以非零退出码结束。这组断言验证的是"点了之后状态确实变化"，仅截图不足以覆盖。


## 攻击图验收

1. 连接包含真实任务的后端，在任务框加载 `task_frontend_e2e_002`。
2. 确认攻击图返回并显示 14 个节点、30 条关系；不得由前端补造或删除关系。
3. 检查自动布局、缩放、平移、节点拖动与 Fit View；选择有多条放射关系的节点，检查可读性。
4. 点击节点和边，核对完整属性、事件/告警证据 ID 与 API 返回一致。
5. 检查关系标签、并行边、反向边；额外用明确标识的 20～50 节点压力数据验证大图、长标签、循环和断开节点。

合成压力数据只验证显示与交互，不能作为真实任务验收证据。后端缺失真实任务时，应明确记为“真实任务未验收”。

公共字段和 API 路径来自：

- `src/types/contracts.ts`
- `src/api/endpoints.ts`

不得在前端重命名公共字段或 API。
