# 公共接口契约 v1.0

真正可执行的字段定义以：
- `common/models.py`
- `schemas/*.schema.json`
为准。

本文用于人类快速阅读。

## 1. API 通用返回

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

## 2. 接口

### GET /api/health
健康检查。

### POST /api/events
输入：`NormalizedEvent[]`

### GET /api/events
输出：`NormalizedEvent[]`

### GET /api/alerts
输出：`Alert[]`

### GET /api/attack-graph/{task_id}
输出：`AttackGraph`

### GET /api/trace/{task_id}
输出：`TraceResult`

### GET /api/tasks/{task_id}
输出：`TaskStatus`

## 3. 禁止的“接口漂移”

下面这些不能自行替换：

| 正确 | 禁止自行改成 |
|---|---|
| `timestamp` | `time` |
| `src_ip` | `source_ip` |
| `dst_ip` | `destination_ip` |
| `host_id` | `hostname` |
| `event_ids` | `events` |
| `technique_id` | `attack_id` |
| `completed` | `done` |

## 4. 向后兼容原则

若以后新增字段：
- 优先新增 optional 字段；
- 尽量不删除旧字段；
- 不直接重命名；
- Schema 重大不兼容变化才升级版本。
