# 十人分工建议模板

| 人员 | 主责模块 | 主要输入 | 必须输出 |
|---|---|---|---|
| 1 | 组长/架构/总集成 | 全部 | 可运行主分支、接口契约 |
| 2 | Windows 日志 | EVTX/Sysmon | NormalizedEvent |
| 3 | Linux 日志 | syslog/auditd | NormalizedEvent |
| 4 | 主机行为 | 进程/文件/系统调用 | NormalizedEvent |
| 5 | 网络流量 | PCAP/会话 | NormalizedEvent |
| 6 | 数据融合/存储 | NormalizedEvent | 标准事件查询能力 |
| 7 | 异常检测 + ATT&CK | NormalizedEvent | Alert |
| 8 | 攻击链关联 | Event + Alert | AttackGraph |
| 9 | LLM 多 Agent / 溯源 | AttackGraph | TraceResult |
| 10 | 前端 + 测试/联调 | 公共 API | 展示、端到端测试 |

成员可调整，但**输入输出契约不要调整**。
